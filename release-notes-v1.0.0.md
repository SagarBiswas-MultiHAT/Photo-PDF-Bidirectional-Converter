# Photo-PDF Bidirectional Converter v1.0.0

A polished Windows desktop app for converting photos to PDF and PDF pages back to images.

## Highlights

- Convert one or many photos into a single multi-page PDF or one PDF per photo
- Convert PDF pages into PNG or JPG images with configurable DPI and quality
- Auto-rotate based on EXIF metadata
- High-quality export options with DPI, page sizing, margins, and embedding modes
- Works fully offline on your local machine
- Portable Windows executable included for quick setup without Python installation

## Features

### Photo to PDF

- Add multiple images at once
- Reorder, remove, or sort photos before conversion
- Choose between one combined PDF or one PDF per image
- Select page sizing, DPI, margins, and embedding quality
- Keep original images, re-encode them as high-quality JPEG, or use lossless PNG embedding

### PDF to Photos

- Convert one or more PDF files into PNG or JPG images
- Pick output folder and image DPI
- Export each PDF page as a separate image file
- Useful for scanning, document splitting, and quick image extraction

## Requirements

- Windows 10/11
- No Python setup required when using the portable executable

## Installation

Download the `Photo-PDF-Bidirectional-Converter-v1.0.0-win64-portable.exe` from this release and run it directly.

If you prefer running from source, see the project README for the Python setup steps.
